训练流程
1. 点「打乱」生成随机打乱 (或输入自定义公式后点「应用」)
2. 观察紫色目标块 (F2L 槽位的角块+棱块), 从解法列表选一条 Cross 解法
3. 点击你预测的目标块在 Cross 完成后会到达的位置 (先角块后棱块)
4. 点「▶ 播放」验证预判; 再次点击同一位置可取消预判
视角操作
· 拖动空白处: 临时旋转观察魔方 (不影响预判), 点「恢复视角」还原
· z2 / y / y': 切换基准视角, 解法按新视角重新生成, 预判块联动跟随
· 播放与判定始终在当前基准视角下进行
标记说明
紫色框: F2L 目标块当前位置 (角块+棱块)
青色框: 你的预判位置 (锚定块, 跟随转动)
求解模式
· Cross: 只求底面十字解法
· XCross: 十字 + 求解槽位一组 F2L 一步到位 (切换求解槽位会重新求解)
· XXCross / XXXCross: 十字 + 2／3 组 F2L；可指定槽位或由解法决定。预判剩余槽位的一组角棱。
· 指法推荐: 点击后计算四朝向建议，可筛选步数、展开全部或全屏；公式会映射回当前视角播放。
槽位
· 预判槽位按钮 FL / FR / BL / BR: 切换要训练的 F2L 槽位 (预判目标)
· 求解槽位可选任意或固定；XX/XXX 固定时恰好选 2/3 槽,
