蓝牙魔方连接教程

先直接连接，遇到问题再排查

大多数情况下不需要提前查 MAC 地址。打开魔方后，在训练页点击「连接魔方」， 按浏览器提示选择设备即可。

进入训练并连接 bluetooth
01

三步直接连接

推荐使用本项目 Android App、Android Chrome，或电脑端 Chrome / Edge。

1

准备魔方

打开魔方电源并转动一层将其唤醒，保持在手机或电脑附近。

请先断开已连接该魔方的计时器、App 或其他网页。
2

发起连接

进入 BLE Cross 训练页，点击「连接魔方」，在系统弹窗中选择你的 GAN 魔方。

首次连接时，请允许浏览器使用蓝牙及附近设备权限。
3

确认同步

按钮显示「已连接」后，转动实体魔方一层，确认屏幕中的 3D 魔方同步转动。

同步正常后即可点「新打乱」开始训练。
02

连接失败，按这个顺序排查

多数问题来自浏览器兼容性、权限或设备占用。

  1. 确认浏览器支持 优先改用 Android App、Chrome 或 Edge，并通过 HTTPS 或 localhost 打开网页。
  2. 检查系统权限 开启蓝牙；在 Android 上同时允许浏览器的「附近设备」权限，部分旧系统还需要定位权限。
  3. 解除设备占用 关闭其他魔方 App、计时器页面和浏览器标签。蓝牙魔方通常只能同时连接一个客户端。
  4. 缩短距离并检查电量 让魔方靠近设备，转动一层重新唤醒；电量过低时先充电或更换电池。
  5. 重新启动连接链路 刷新训练页，再关闭并重新打开系统蓝牙；仍失败时重启浏览器或设备。
info
设备列表里找不到魔方？

先转动魔方保持唤醒，再重新点击「连接魔方」。不要先在系统蓝牙设置里配对。

03

必要时再填写 MAC 地址

MAC 是部分 GAN 设备协议解密的辅助信息，不是连接前的必填项。

什么时候需要？

项目会优先自动识别。只有连接 GAN Gen2 等设备时，页面提示自动获取失败， 才需要在训练页展开「MAC」输入框并手动填写。手动 MAC 是自动识别失败后的兜底， 不是连接前的必填项。

从哪里找？

  1. 优先查看魔方底盖、电池仓或包装标签。
  2. 地址通常由 12 位十六进制字符组成，例如 AA:BB:CC:DD:EE:FF。
  3. 填入训练页的 MAC 输入框，点击「用 MAC 连接」；地址会保存在当前浏览器本地。
privacy_tip

浏览器内部页仅作辅助

桌面 Chrome 可尝试打开 chrome://bluetooth-internals/#devices， Edge 可尝试 edge://bluetooth-internals/#devices，再启动扫描。

受操作系统、浏览器版本和隐私策略影响，内部页不保证显示真实 MAC， 有时只显示匿名或随机标识。

iPhone 和 iPad 通常只向应用提供匿名标识，网页无法读取真实蓝牙 MAC。 如设备确实需要 MAC，请先从魔方本体、电脑或 Android 设备上查找。

04

浏览器与平台兼容性

浏览器升级后能力可能变化，以下以本项目的推荐连接路径为准。

平台 Web Bluetooth 建议
本项目 Android App 推荐原生蓝牙 连接最直接，不依赖浏览器 Web Bluetooth。
Android Chrome 支持 允许蓝牙及附近设备权限后直接连接。
电脑 Chrome / Edge 支持 使用最新版浏览器，通过 HTTPS 或 localhost 打开。
Samsung Internet / Opera 视版本而定 部分版本或实验设置可用，不作为首选路径。
Firefox 不原生支持 第三方扩展和本地服务兼容性不确定，建议改用 Chrome / Edge。
Safari（macOS / iOS） 不原生支持 建议在电脑或 Android 上使用 Chrome / Edge，iOS 无法提供真实 MAC。

准备好了吗？

打开并唤醒魔方，返回训练页点击「连接魔方」。
