TS主版本 Cube.serialize() 测试教程

注意: TS主版本依赖 Three.js + Vue，不能直接在简单 HTML 中运行。 需要通过 Vue 应用的浏览器控制台来测试。

测试步骤

步骤 1: 启动开发服务器

cd /dd/workspace_trae/cuber
NODE_OPTIONS=--openssl-legacy-provider npm run watch

等待编译完成，浏览器打开: http://localhost:8080

步骤 2: 打开浏览器控制台

按 F12 或右键 → 检查 → Console

步骤 3: 在控制台执行

// 获取 Vue 应用实例
const app = document.querySelector('#app').__vue__;

// 获取 world 对象
const world = app.$children[0].world;

// 获取 cube 对象
const cube = world.cube;

// 应用操作（如 R）
cube.twister.setup('R');

// 输出状态字符串
console.log(cube.serialize());

一键测试脚本

复制以下脚本到控制台，自动运行测试：

// TS主版本 serialize() 测试脚本
(function() {
  const app = document.querySelector('#app').__vue__;
  if (!app) {
    console.error('错误: Vue 应用未加载');
    return;
  }
  
  const world = app.$children[0].world;
  const cube = world.cube;
  
  console.log('=== TS主版本 serialize() 测试 ===');
  
  const tests = [
    { moves: '', label: '还原状态' },
    { moves: 'R', label: 'R 转动' },
    { moves: 'R R\'', label: 'R R\' = 还原' },
    { moves: 'R2 R2', label: 'R2 R2 = 还原' },
  ];
  
  const expected = {
    '': 'UUUUUUUUURRRRRRRRRFFFFFFFFFDDDDDDDDDLLLLLLLLLBBBBBBBBB',
    'R': 'UUFUUFUURRRRRRRDRRFFFFFDFFBDDRDDBDDBLLLLLLLLLUBBUBBUBB',
  };
  
  for (const test of tests) {
    cube.twister.setup(test.moves);
    const state = cube.serialize();
    const exp = expected[test.moves];
    const pass = exp ? (state === exp) : 'N/A';
    
    console.log(`${test.label}: ${state}`);
    if (exp && pass !== true) {
      console.log(`  期望: ${exp}`);
      console.log(`  结果: ${pass ? 'PASS' : 'FAIL'}`);
    }
  }
})();

对比 verify CLI

在终端运行 CLI 测试：

cd /dd/workspace_trae/cuber
npm run verify apply "R"
# 输出: 状态: UUFUUFUURRRRRRRDRRFFFFFDFFBDDRDDBDDBLLLLLLLLLUBBUBBUBB

对比两者输出的状态字符串是否一致。

说明

TS主版本 serialize() 输出顺序: URFDLB (U→R→F→D→L→B)

verify CLI 输出顺序: 同样 URFDLB

两者应该输出相同的状态字符串。
