# 六格观察界面的两种方式

在 `?mode=pll6` 中使用“观察方式”切换：

- **同色分组**：新默认方式。先分左侧五形态，再从左到右把右三格归入同色组；54 种同色模式覆盖 84 种朝向，其中 56 种朝向可以直接确定 PLL，另外 28 种最后补一次邻／对色。最后比较统一为 5–6、4–6 或 2–6。三段流程不等于三次两格比较。
- **原九大类**：保留原九类特征、学习资料、原图核对稿、当前特征提示与连线。原九类训练筛选在两种观察方式下均可使用。

切换只改变学习资料和提示，不改变当前题目、计时或答案；观察方式会保存在浏览器中。已保存的原九大类选择保留，已经删除的 `scan` 选择自动迁移为同色分组。

同色分组的学习卡片按左侧“团、眼、棒左、棒右、灯”展开，另有 12 种冲突模式的最后一问速查。A/B/C/D 仅代表不同颜色组；卡片展示一种标准配色代表题面，当前提示以实际题面为准。训练提示不提前展示 PLL 名称，学习卡片则包含答案。

两种方式共用文字避让布局：关系线先画，文字标签最后画，底板与边框透明；标签在视口内错开，必要时换行或用引导线关联原位置，不改变关系线端点，也不阻挡魔方操作。

## 实时观察

- 六格特征以当前 3D 魔方状态为准，不再锁定初始题面。鼠标操作、动画、实体跟随、直接设置状态及重试后都会重新核验。
- 转动过程中暂时清空特征与连线，完成后重新识别；非 PLL 状态不保留上一状态的提示，恢复到 PLL 后自动重新显示。
- 隐藏“显示当前特征”时仍会更新识别结果，学习资料也跟随当前状态；重新勾选后显示最新提示。
- 观察变化不会改写训练题目、答案或历史记录。只改变相机视角时更新连线投影。
- 相同序列化状态复用识别结果，避免每帧重复执行 PLL 合法性核验。

84 种朝向为 21 个 PLL 各四种 U 调整，并非 84 个不同 PLL。标准颜色示例不随当前题目的 z2 改变；当前题面提示根据实际六格重新计算。

上一版逐对比较的界面入口、学习卡片与实时提示已移除；离线分析与验证脚本保留供参考，见 `pll6-shortest-paths.md`。

## 维护与验证

- `npm run generate:pll-scan`：根据优化器重新生成浏览器使用的精简目录 `src/ble/pll-six-scan-catalog.ts`。
- `npm run test:pll-scan`：检查冲突、单向顺序、优化结果、运行时目录一致性及 AUF/z2 变体。
- `npm run test:pll-equality`：检查同色优先搜索与界面运行时的 54 种模式、84 种朝向、12 组冲突消歧及 672 个 AUF/z2 变体。
- `npm run test:pll-labels`：检查密集文字标签避让、视口边界、长文换行与布局稳定性。
- `scripts/verify-pll6-label-layout.js`：检查两种观察方式、84 种朝向在 360/390/1280 像素宽度下的文字重叠、裁切、标签与绘制顺序。
- `scripts/verify-pll-six-equality.js`：检查默认方式、五形态学习卡片、最后一问、两种方式切换、实体转入非 PLL 后清空提示、偏好保存及手机布局。
- `scripts/verify-pll6-live-features.js`：检查逐对比较移除、U 转动、切换 PLL、进入非 PLL、逆转恢复、实体跟随及旧偏好迁移。

原九类资料仍在 `docs/pll-six-sticker-observation.md`，没有被新算法替换。
