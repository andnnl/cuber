# 魔方栈 v1.0.15

发布日期：2026-11-05。Android versionCode：16。

## 更新内容

- CFOP 播放区域新增 GIF 导出按钮。
- 公式计时支持实体魔方及鼠标、触摸、键盘操作；预打乱支持左右轮流和始终操作左侧两种连续训练方式。
- 修正默认配色与出题前 z2 的对应关系：未勾选白顶绿前，勾选黄顶绿前；保留自定义配色。
- 六格观察法采用同色分组优先、最后邻色／对色消歧的识别方式，保留旧九类观察法，移除“逐对比较”界面选项。
- 覆盖 84 个 PLL 朝向及 672 个 AUF/z2 变体的冲突检查；提供 54 个同色模式及 12 组冲突消歧参考。
- 六格观察特征随当前 3D 魔方状态重新计算；非 PLL 状态清空提示，回到 PLL 后恢复。
- 优化 3D 标注的避让、换行和边界布局，标注底板与边框透明。
- 更新非标 F2L 多方向案例预览与目标槽位显示。

## 安装包

- GitHub：Android debug/release APK、Windows x64 安装包、Linux x86_64 AppImage。
- Gitee：Android debug/release APK；桌面包按 90 MiB 分卷，附带合包脚本及 SHA-256 校验清单。
- Windows：将全部分卷与对应 `unpack.bat` 放在同一目录后运行脚本。
- Linux：将全部分卷与对应 `unpack.sh` 放在同一目录后运行脚本。

- GIF 导出、打包入口、分卷与还原保护测试。
