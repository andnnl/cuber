# 魔方栈 v1.0.16

发布日期：2026-11-06。Android versionCode：17。

## 更新内容

- 非标 F2L 学习页和公式训练的选择界面统一使用公式库风格的三维图标。
- 按角块当前位置识别分类，保留实际目标角块、配套棱块及初始已完成槽位的颜色，无关块变黑而不移除块体。
- 学习页及公式计时训练新增“大魔方隐藏无关块（变黑）”开关，独立保存设置，切换时不重置题面、动作或计时。
- 训练中的下一题预览同步应用隐藏设置；完成判定读取未遮罩的实际状态。
- 公式训练接入非标 F2L 多解法题池、选题及统计，支持镜像小魔方观察背面和底面。
- 改善实体魔方切层与漏步恢复，避免旧状态或跨题动作影响当前训练。

## 安装包

- GitHub：Android debug/release APK、Windows x64 安装包、Linux x86_64 AppImage，以及 SHA-256 校验清单。
- Gitee：Android debug/release APK；桌面包按 90 MiB 分卷，附带合包脚本及 SHA-256 校验清单。
- Windows：全部分卷与对应 `unpack.bat` 放在同一目录后运行脚本。
- Linux：全部分卷与对应 `unpack.sh` 放在同一目录后运行脚本。
- 安装包未进行发行商代码签名；Android release 沿用项目现有签名配置。
