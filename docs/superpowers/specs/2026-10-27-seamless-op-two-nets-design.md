# 无缝 OP：当前与 OLL 后双展开图

## 目标

在无缝 OP 页的 3D 魔方下方增加两张顶层展开图，使练习者直观看到贴纸从题面到 OLL 完成后的去向。沿用现有案例生成和播放，不改变判题依据。

## 布局与可见性

每张图的 U 面九格居中，B 面顶层三格在上、L 面三格在左、R 面三格在右、F 面三格在下。四角不渲染底色或占位块。左图的 B 面三格也完全留空，因为观察当前实体魔方时通常不可见；右图保留 B 面三格。桌面左右排列，手机窄屏上下排列，不产生横向滚动。两图的格子边框、间距、圆角和标题采用已确认的美化草图。

左图始终显示题面 `beforeFacelets` 的对应 18 格真实贴纸颜色，右图对应 `afterFacelets` 的 21 格。答题前，右图所有格子仅显示统一的中性色与位置提示，不泄露实际颜色；答对或进入复盘后，才显示 `afterFacelets` 的真实颜色。演示 OLL 时，左图可按当前播放步数显示对应状态，但重试必须回到同一题的原始题面。

两图均用当前 `PaletteData.getColor(facelet)` 映射颜色，与同一页 3D 魔方共享默认、预调及自定义配色；不硬编码黄色、绿色等颜色。若用户改变配色，下一帧同步刷新。非贴纸空隙透明，不使用 `Core` 色覆盖。

## 箭头与数据

复用 `traceOpStickers` 的稳定贴纸身份和每步位置。左图的箭头从可见的题面贴纸中心出发，指向它在完整 OLL 后位于展开图的位置；从当前步开始绘制，步进和自动播放时更新箭头起点，终点保持完整 OLL 的目标位置。左图不显示 B 面，因此来源或终点落在 B 面时不画伪造端点，改用目标编号文字提示；右图不画箭头。仅对 U 与侧面顶层映射得到的可见来源绘制，避免过量交叉线；与现有 F/R、L/F 六格窗口同步高亮。箭头的线条与箭头头部不得遮住贴纸颜色，可通过显示线索开关隐藏。

## z2 选项

页面增加可记忆的「出题前 z2」复选框，默认关闭。开启后，在现有整体朝向 `Y` 之前加 `z2`，即题面构造为 `z2 · Y · P⁻¹ · O⁻¹`，无 PLL 时省略 `P⁻¹`。切换开关时，保持当前目标 PLL、OLL 和 `Y`，重新生成并验证同一题的 z2／非 z2 版本，重置播放与计时；不要只旋转画面或仅改变颜色标签。新题继承开关状态。训练记录保存 z2 开关及真实题面／完成状态，复盘时按记录恢复。

## 验证

- 逐面核对 U 九格及 L/F/R/B 顶层各三格在两图中的索引与 3D 魔方序列化颜色一致；左右空角、左图 B 面确实透明。
- 任意包含 `y/y'/y2` 与 z2 的题，模拟完整 OLL 后，右图颜色与 `afterFacelets` 一致；无 PLL 题仍六面还原。
- 默认答案隐藏，正确答案后揭示；F/R 与 L/F 切换不改贴纸身份；重试与复盘保持原题。
- 浏览器检查桌面和手机布局、箭头随步数更新、配色与 3D 魔方一致，运行 `test:op` 与 Web 构建。
