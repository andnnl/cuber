# 无缝 OP：换 PLL 重试与隐藏预测图

## 目标和范围

在无缝 OP 训练页「重试同题」右侧增加「换 PLL 重试同题」按钮；在「OLL 后 · 预测结果」卡片右上角增加「隐藏」复选框。仅调整无缝 OP 的出题和显示，不影响公式库、蓝牙连接及其他训练页。

## 换 PLL 重试同题

- 保留当前案例的 OLL 名称及公式、整体转体 `y`、`z2`，从当前选择的 PLL 池挑选一条与当前目标不同的 PLL。当前是「无 PLL」时也选择有 PLL 的题，即使出题类型设置为「不含 PLL」也不修改这一设置；下一次「新题」仍按该设置正常出题。
- 用 `validateOpCase` 为新 PLL 与保留的 OLL、朝向、`z2` 重新构造、验证题面。选择池仅有当前 PLL 时，显示「没有可更换的 PLL」并保留原题；候选公式均校验失败时提示错误，亦不修改原题。
- 成功后使用 `OpTraining.replace` 清除复盘只读状态、揭示结果并重启计时；界面调用 `loadCase` 将 3D 魔方退回新题起始状态、重置播放进度、更新箭头与预测图。已有训练记录不删除，新题答题照常记录。

## 隐藏预测图

- 在预测结果标题右侧放「隐藏」复选框；勾选时只收起该卡片内的预测展开图，标题、复选框仍可见，取消勾选立即恢复。
- 持久化勾选状态到现有 `seamlessOpSettings`，与「显示线索」分开控制；默认不隐藏。卡片隐藏不改变当前题、六格来源计算、已选箭头或答案，也不影响「当前 · 题面」面板。

## 验证

- 纯函数测试覆盖保留 OLL／朝向／`z2`、从「无 PLL」切换、排除原 PLL、仅有原 PLL 和校验失败时原题不变。
- 浏览器交互测试检查按钮位置、题面和计时重置、预测图显示切换及刷新后记忆。运行 `npm run test:op`、生产构建、`git diff --check`。
