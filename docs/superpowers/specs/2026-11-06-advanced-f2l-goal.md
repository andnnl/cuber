# 非标 F2L 完成判定

- 每题以实际初始打乱状态为基准，保存当时已正确归位的十字棱块和完整槽位。
- 成功要求这些十字棱块仍正确、这些槽位仍完整，并且本题目标槽位的角块与棱块均归位且朝向正确。
- 初始尚未完成的其他槽位及错误的十字棱块，不额外要求修复；标准 F2L 仍要求十字和前两层完成。
- 使用初始中心色标识目标块，整体转体后继续检查同一组实体块，不因当前前右位置变化而换目标。
- 出题方向表示角块当前被困的位置，不是目标归位槽位。按所选公式逆操作找到目标角块（困棱类取对应顶角），再按角块真实配色与中心色确定 FR／FL／BL／BR 归位槽位。
- 新题携带真实目标槽位；旧记录重新训练时按题目 ID 和公式从新题池纠正旧元数据，不修改历史成绩。无法恢复有效目标时不根据方向 ID 猜测成功。
- 基线依附于每个题目对象；重试沿用原始题面，预打乱切题按下一题自己的初始状态重新确定基线。
- 屏幕操作与实体跟随共用这一判定，未知时间补步不计有效成绩的规则保持不变。

例如 AF2L 1 前右题：被困在 FR 的角块应归位 BR，不能只因 FR 已完成而判成功；BR 完成且初始已正确部分仍保持时，允许 FR 继续未完成。

验证：`npm run test:formula-timer` 穷举 598 条公式的目标实体块，覆盖两种 z2 设置与四种 y 转向；`scripts/verify-formula-timer-adv-f2l-target.js` 验证屏幕、实体跟随及旧题目目标纠正；`scripts/verify-formula-timer-adv-f2l-goal.js` 覆盖两种预打乱布局的独立基线与连续成功。
