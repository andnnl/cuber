# BLE Cross 3D 背景色选择设计

## 背景

BLE Cross 的 3D `viewport` 使用透明 WebGL 画布，目前背景由页面主题透出。用户在开启「半透明」或「隐藏无关」后，需要根据贴纸和透明块颜色切换更易辨认的背景，但「菜单 → 显示 → 暗黑」会修改全局 Vuetify 主题，影响所有页面，不符合本次仅调整 BLE Cross 3D 区域的要求。

## 目标

- 在「隐藏无关」右侧增加紧凑的背景色下拉框。
- 提供 10 个可直接辨认的预设色块，包含白色和暗黑。
- 支持打开系统调色器选择任意自定义颜色。
- 选择后立即更新 BLE Cross 训练页的 3D 背景，并在刷新后恢复。
- 背景色不影响全局主题、其他训练模式、底部操作面板或魔方状态。
- GIF 录制继续自动使用当前 3D 背景色。

## 非目标

- 不修改 `PreferanceData.dark` 或 Vuetify 全局暗黑模式。
- 不给其他模式增加背景选择器。
- 不修改魔方贴纸、骨架、透明度或灯光颜色。
- 不实现渐变、背景图片、透明背景或预设编辑功能。

## 交互设计

背景选择器位于「隐藏无关」复选框右侧，XCross 槽位选择器之前。

- 收起状态显示一个带边框的当前颜色色块，旁边显示下拉箭头。
- 点击后展开一个小型面板，以网格形式展示 10 个预设色块。
- 每个色块带 `title`，显示中文名称和十六进制颜色值。
- 当前选中色块使用清晰的描边或选中标记。
- 面板末尾提供「自定义」入口，使用 `<input type="color">` 打开浏览器或 WebView 原生调色界面。
- 预设色和自定义色均在选择时立即生效，不需要确认按钮。

预设颜色固定为：

| 名称 | 色值 |
| --- | --- |
| 白色 | `#FFFFFF` |
| 浅灰 | `#F3F4F6` |
| 米白 | `#FFF8E7` |
| 淡黄 | `#FFFDE7` |
| 淡绿 | `#E8F5E9` |
| 淡青 | `#E0F7FA` |
| 淡蓝 | `#EAF2FF` |
| 淡紫 | `#F3E8FF` |
| 淡粉 | `#FCE7F3` |
| 暗黑 | `#121212` |

## 状态与持久化

BLE Cross 组件新增当前背景色状态，默认值为 `#FFFFFF`。使用独立的 `localStorage` 键 `bleBackgroundColor` 持久化，不写入全局 `preferance` 对象。

加载时只接受完整的 6 位十六进制颜色：

```text
^#[0-9A-Fa-f]{6}$
```

无值或非法值回退为白色。保存时统一转为大写，保证预设选中判断稳定。

## 渲染边界

`Viewport` 的 WebGL renderer 已启用 `alpha: true`，画布清屏透明。因此背景色绑定在 BLE Cross 模板中包裹 `<viewport>` 的全屏绝对定位容器上，不修改共享 `Viewport` 组件和 renderer。

该边界保证：

- 颜色仅作用于 BLE Cross 的 3D 区域。
- 底部 `ble-card` 继续保持自身样式。
- 其他使用共享 `Viewport` 的页面不受影响。
- `gifBackColor()` 从 viewport 向父元素查找首个非透明背景时，会自然读取新颜色，无需新增 GIF 专用状态。

## 测试

扩展 `scripts/verify-blecross-recompute.js`，覆盖：

1. 页面默认背景为白色，且下拉框包含 10 个预设色。
2. 选择暗黑预设后，3D 背景立即变为 `#121212`，`bleBackgroundColor` 同步持久化。
3. 自定义颜色通过统一保存入口立即生效并持久化。
4. 页面刷新后恢复已保存颜色。
5. 非法持久化值回退为白色。
6. `gifBackColor()` 读取到当前 3D 背景色。
7. 背景切换前后 `cube.serialize()` 不变。
8. 既有 BLE、透明材质、公式显示和重置回归继续通过。

## 验收标准

- 用户无需打开全局菜单即可在「隐藏无关」右侧直观看到并切换背景色。
- 10 个预设颜色均以实际色块展示，白色和暗黑可直接选择。
- 自定义调色器可设置任意 6 位 RGB 颜色。
- 设置只影响 BLE Cross 的 3D 背景，刷新后仍保留。
- GIF 背景与当前 3D 背景一致。
- 魔方显示状态、判定和其他页面行为不变。
