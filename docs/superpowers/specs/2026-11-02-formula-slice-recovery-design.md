# 公式计时切层补步设计

GAN Gen3/Gen4 发生 MOVE 序号断档时，保留已接收动作并异步请求官方历史窗口（Gen3 `68 03`、Gen4 `D1 04`）；通知解析不得等待 GATT 写入。历史事件按序号进入已有 FIFO，重复/迟到事件拒绝；在历史无响应时用完整状态作为最终核验，不将其伪造成可计时的逐步动作。固定 `serial=0` 的状态帧不得重置已推进的 MOVE 序号。积压设置有界保护，溢出时明确进入不可核验分支而非悄悄成功。

公式计时界面继续依据实体状态补步账本检查时间：有时间戳的步才计入 TPS；未知时间的中间步不产生有效成绩。无法唯一补步时可根据相邻实体快照推得唯一净变化（最多两次外层操作），仅用于无动画校正画面；更多/歧义变化则停止成绩并复位题面，告知重试。对 M2/S2/E2 两侧快速转动、历史迟到、状态帧迟到和切题边界测试。
