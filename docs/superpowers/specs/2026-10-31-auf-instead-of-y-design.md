# 三界面出题前 AUF 设计

无缝 OP、公式计时和六格观察法出题时，不再随机在逆公式前执行整体 `y/y'/y2`；改为随机 `无/U/U'/U2`。已有可选的 `z2` 底色切换仍保留，六格观察法在逆 PLL 后追加的第二次随机 AUF 也保留。已保存的旧成绩题面保持原样，新的题面从新规则生成。

无缝 OP 的有 PLL 案例继续检验 OLL 后的 F2L、顶层定向及 PLL 名称；无 PLL 案例允许 OLL 后只差一个顶层 AUF，显示为“无 PLL”。更换 PLL 时保留本轮前置 AUF。公式计时的 F2L 题面不额外添加前置 U；OLL、PLL 用新前置 AUF 生成，并验证原有完成目标。六格的题面按 `z2? → 前置 AUF → 逆 PLL → 后置 AUF` 生成。

验证：分别覆盖四个前置取值；无缝 OP 的有／无 PLL、z2 组合和换 PLL；公式计时 F2L／OLL／PLL 出题；六格 21 个 PLL 与两次 AUF 的组合。蓝牙事件与计时状态机不变。
