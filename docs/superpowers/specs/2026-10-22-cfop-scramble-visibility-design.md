# CFOP 公式打乱与播放可视化

CFOP 输入框旁增加「按公式打乱」按钮。仅接受空格分隔的六面动作（`U R F D L B` 及 `'`、`2` 后缀）与可选的末尾 `z2`，或 54 位 `URFDLB` 状态。无效输入不改动当前魔方；有效输入从还原状态建立新的 3D 打乱，取消旧解法，并按现有自动十字选项搜索。随机打乱保持原逻辑。

播放控制旁增加「半透明」「隐藏无关」两个独立开关，默认关闭。两者使用现有 BLECross 的材质规则，开关关闭立即恢复正常贴纸与骨架。求解路线的十字阶段保留四条底面十字棱块；F2L 阶段保留十字、当前组与下一组的角棱块；到达路线末尾后继续保留十字。目标块按贴纸颜色身份识别，而不是固定位置；`z2` 输入将逻辑身份转换为实体颜色。跳步、逐步动画、自动播放、蓝牙跟练与路线变更统一刷新，不覆盖现有彩色追踪。

测试覆盖无效输入、末尾 `z2`、十字／当前组／下一组签名，以及播放跳步和开关切换时的材质刷新；构建检查 TypeScript 和模板。
