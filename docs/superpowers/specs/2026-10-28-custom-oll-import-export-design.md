# 自定义 OLL 公式导入、导出与 Linux 本机安装

## 范围

- 在无缝 OP 的「选择 OLL → 自定义分组」增加「导出 JSON」「导出纯文本」「导入文件」操作。
- 两种文件格式包含同一份自定义 OLL 公式库，公式库页面继续共享这份数据；内置 OLL 和训练记录不在导入、导出范围内。
- 导入适用于网页和桌面版，下载使用浏览器保存文件，导入使用本地文件选择器。无需 Electron 专有文件系统权限。
- 功能构建并验证后，将本机 Linux 桌面快捷方式更新到新构建的 AppImage；保留原用户配置、训练记录和旧安装包。

## 文件格式

JSON 导出 UTF-8 文件，结构为 `{ "version": 1, "items": [{ "name": "...", "origin": "..." }] }`。导入也接受此前公式库存储格式中附带 `id` 的条目；导出的文件不依赖原设备的 ID。

纯文本导出 UTF-8，每行一条，格式为 `名称|公式`。导入时也允许一行只写公式，自动命名为「导入 OLL 1」「导入 OLL 2」等。忽略空行；名称和公式两侧空白会去除。名称中的 `|` 不被支持，公式中的 `|` 视为无效符号。根据文件扩展名选择 `.json` 或 `.txt` 解析；不支持的扩展名明确提示。

## 导入合并规则

1. 先完整解析文件并对每条公式调用现有 OLL 解析及案例校验逻辑；名称为非空且不超过 40 字。格式错误、无效公式、超出文件大小限制或导入后超过已有的 100 条上限时，整次导入失败，原数据不变。
2. 使用解析后的转动序列作为去重键，忽略空格、括号分组等文本差异。先与现有库比较，再在文件内部去重；重复公式跳过，现有条目及其名称、ID 保持原样。
3. 不同公式但名称相同，给新条目追加 ` (2)`、` (3)` 等最小可用序号；必要时截短原名以符合 40 字限制。导入的 ID 重新生成，避免撞到现有 ID；新条目默认不改变当前已选 OLL 集合。
4. 校验通过后一次性保存合并结果；报告新增、跳过重复与自动改名的数量。自定义分组和公式库页面重新读取时立即看到结果。

## 验证与安装

- 单元测试覆盖 JSON/纯文本往返、仅公式行、语义重复、文件内重复、同名改名、无效输入不写入与 100 条上限。
- 浏览器测试覆盖下载按钮、文件选择器导入和两个界面的共享显示。
- 构建 Linux AppImage 后检查包内新界面；使用本机已有快捷方式所指向的 `~/.local/opt/cuber/` 路径安装新包并更新快捷方式，不清除 Electron 用户数据。验证启动与自定义公式留存。

## 非目标

- 不自动云同步；不导出蓝牙 MAC、训练记录或全局设置。
- 不删除或覆盖旧公式，也不自动选择新导入的公式作为出题池。
