# 公式计时 TPS 与出题前 y 设计

- TPS：每条被计时器接受且有可靠时间戳的实体蓝牙转动计一步，包括切层拆出的每条外层转动；重复序号、不确定时间的补步不计入；恢复帧中可核验时间戳的转动按原路径接收并计入。每题保存步数；成功且拧动时长大于 0 时展示 `步数 / (毫秒 / 1000)`，保留两位小数。失败和旧记录显示 `—`。统计取成功且有有效步数与时长的逐条 TPS 算术平均，沿用现有取样方式。
- 出题前 y：在 z2 右侧增加 `无 / y / y' / y2` 下拉框，默认无，持久化在现有设置里。选择后立即出新题。打乱串顺序为可选 `z2`、可选 `y`、原有随机 AUF/公式逆操作；画面和复盘都使用完整打乱串。旧存储兼容默认无。
- 用现有 formula-timer 测试脚本覆盖计步、旧数据兼容、统计及各分类打乱；运行 `npm run test:formula-timer` 与 `npm run build`。
