# 公式计时统计与重点补练设计

日期：2026-11-01

## 目标与范围

在 `mode=formulatimer` 增加统计入口，帮助用户对 F2L、OLL、PLL 的反应速度、拧动速度和成功率进行分析，找到值得重复训练的公式。保留现有训练、公式选择、成绩记录和蓝牙判定流程，不改变已有记录的含义，也不改动训练成功/失败判定。

本次只做本机现有记录的统计展示和临时重点训练；不做云同步、记录迁移、公式算法纠正或训练记录的批量删除。

## 页面与交互

统计从公式计时页进入，手机端使用单列顺序：

1. 总体成绩概览：当前分类的有效尝试、成功率、平均反应时间、平均拧动时间及各自有效样本数。
2. 重点补练：按“拧动慢”“反应慢”“失败较多”分类列出公式，允许一键进入当前分类的临时重点训练。
3. 各公式排行：每张卡显示公式名、平均反应时间、平均拧动时间、成功率、有效样本数和标签。展开单张卡，显示这条公式的最近成绩趋势及“只练这一条”。同一时刻只展开一个趋势图，避免手机端图表拥挤。完整列表包含样本不足的公式。

顶部可选 F2L／OLL／PLL、取样口径、N 值（10／20／50／100）。默认“每个公式最近 20 次”，另一口径是“当前分类最近 N 条，再按公式分组”。分类和取样设置在统计页独立记忆，不修改训练页当前分类、原公式选择或出题方式；统计页顶部的说明始终展示实际口径和 N。N 以包含失败、中断的原始记录条数计，随后按结果类型决定不同指标的分母。

趋势图横轴是入选记录的发生顺序，纵轴为秒；成功记录可分别显示反应与拧动点／线，停转失败单独标记，连接中断不画成速度点。图表上的数据和卡片统计严格使用同一批入选记录。无数据时显示引导文案，不绘制假值；手机窄屏下卡片和图表不横向溢出。

## 数据口径与标签

先按分类和取样口径选择记录，再按 `category + id` 分组；时间顺序按 `at` 降序，时间相同保持原记录顺序。统计范围包括历史上已删除公式的记录，名称以记录内保存的名称为准；公式身份使用分类及 ID，不按名称合并。

- 有效尝试 = 成功 + 停转失败；连接中断不参与成功率分母。
- 成功率 = 成功次数 / 有效尝试次数；分母为零时显示“—”。
- 平均拧动时间只包含成功且 `durationMs` 有效的记录。
- 平均反应时间只包含成功且 `reactionMs` 为非负有限数的记录；旧记录没有反应时间时不参与该平均，单独显示有效样本数。
- 样本不足：少于 3 次成功记录的公式不进入“拧动慢”和“反应慢”榜。完整列表仍显示已有指标及“数据不足”。“失败较多”独立要求至少 5 次有效尝试，不受成功记录不足 3 次的限制。
- 拧动慢：至少 3 次成功，平均拧动时间严格大于训练页现有 `slowSeconds` 阈值。统计页明确标明其采用的是“样本平均”，而训练页已有“只练慢公式”采用的是最近 5 次成功记录的中位数；两者不混为一谈。
- 反应慢：至少 3 个有效反应时间样本，平均反应时间严格大于当前分类内、具有至少 3 个有效反应样本的各公式平均反应时间的中位数的 1.5 倍；没有足够基准时不贴标签。
- 失败较多：至少 5 次有效尝试且成功率严格低于 80%。

重点补练卡按对应问题严重程度排序：拧动慢按平均拧动时间降序；反应慢按平均反应时间降序；失败较多按成功率升序。相同时按名称、ID 稳定排序。一个公式可以同时有多个标签，完整排行中只出现一张卡；补练组内可分别出现。默认完整排行按平均拧动时间降序，缺乏成功样本的放在最后。

总体成绩按当前选中样本中的全部记录直接计算，而不是先求每公式均值再平均。统计结果与原训练页已有 `recentMedian` 筛选结果可以不同，页面文字明确区分。

## 临时重点训练

从某个补练分组进入时，只用该组当前可出题公式构成临时题池；从单公式详情进入时只用这一条。优先遵守训练页原有的重复同一条／随机下一条设置和“出题前 z2”设置；临时题池优先于原公式勾选和原 `slowOnly` 筛选，确保选中的统计公式能出题。

临时题池仅保存在当前页面会话的内存中，不写回 `selectedIds`、`slowOnly`、`nextMode` 或其他训练设置。训练区显著显示“临时重点训练”和退出按钮；退出、切换训练分类或离开页面时清除临时题池，恢复原设置下正常出题。单公式模式即使原出题方式为“随机下一条”也始终只抽这一条。统计页不自动修改原始历史记录。

如果历史公式 ID 已不在当前公式库中，它仍在统计列表里，但“只练这一条”不可用并提示原因；一个补练分组没有可出题公式时禁用进入按钮。当前题进行中切入临时训练时明确换题并重新计时，不将未开始的题记为失败；已开始的题按现有中断规则处理，避免静默丢失训练结果。

## 代码边界和存储

把纯统计计算放在独立模块：输入记录、分类、口径、N 和秒数阈值，输出概览、各公式摘要、标签和图表点。UI 只负责取样参数、展开状态和临时题池的进入／退出；不让图表各自重复计算指标。继续读取 `FormulaTimerStore` 中的 `formulaTimer.v1` 记录，保持现有记录结构与兼容逻辑。

统计页的分类、口径、N 使用独立的本机偏好键保存，读取异常时退回默认值；统计偏好损坏不能让训练记录读取失败。临时题池和卡片展开状态不持久化。统计只在记录或筛选条件变化时重算，不随计时器逐帧重算。

## 验证

使用固定数据覆盖两种取样口径、同时间戳顺序、不同分类同 ID、三类标签的边界值、样本不足、旧记录缺少 `reactionMs`、中断排除、总体加权口径、已删除公式、空数据和异常偏好。页面检查手机窄屏布局、统计与图表同源、临时题池覆盖原勾选及慢公式筛选、退出后原设置不变、单公式随机模式以及换题时的既有计时语义。
