# Cross 宽转候选接入设计

## 背景与目标

Rust 项目 `/dd/workspace_rust/cube_cross_solve` 的 `master`（合并提交 `91d2825`）已提供 `recommend_wide_cross_cached_js`、`recommend_wide_cross_js`、`cross_wide_table.bin` 和独立 Worker 示例。本项目要把这套含 `u/u'` 的少 B 十字候选接入 `crossf2l` 与 `blecross` 两个界面的指法推荐。原 Cross 最短／+1／+2 结果及 XCross／XXCross／XXXCross 推荐保持原样；宽转候选不能改变训练目标、记录、最优步数或自动重试。

## 方案选择与界面

讨论过两种布局：用标签切换原解法与宽转解法，或在原列表下方使用独立折叠区。选择后者。两处推荐面板的普通布局与全屏布局都显示「`u/u'` 少 B 候选」折叠区，仅 Cross 模式可展开；默认收起。展开后加载并搜索，原推荐始终独立可见。四朝向按 Rust 返回的 `F/L/B/R` 分组，每组最多 3 条；每条展示公式、动作数、当前观察正面的 B 次数、指法和握姿，沿用现有简单／完整指法切换。`blecross` 还沿用其现有逐步、播放、GIF、返回起点的预览控件；`crossf2l` 沿用选中公式与现有播放控制。

宽转区注明「最多 8 个动作、搜索有预算、并非最短证明」，显示 Rust 返回的 `limited`，说明 `u/u'` 的具体触点待人工校验、可能影响 F2L。宽转结果不使用原「最短／+1／+2」筛选标签，因这组候选不保证与普通面转的最优步数具有相同定义。宽转区单独展示加载、空结果、错误和重试状态；失败不遮挡或清空原推荐。

## 资源与求解边界

将已构建的 Rust WASM 胶水、WASM 二进制和版本化 `cross_wide_table.bin` 同步到项目可分发资源。Webpack 将 BIN 和宽转 Worker 复制进 `dist`，保留既有 `cube_cross_table.bin` 与 `joint_table.bin`。Android 后续同步 `dist` 时必须包含 BIN、Worker 和新版 WASM；本次不改 Rust 算法，也不生成新的 APK。

宽转请求使用独立模块 Worker 与专属客户端，输入是 54 位 URFDLB 完整状态，先加载同版本 WASM，再获取并校验 BIN，调用 `recommend_wide_cross_cached_js`；文件缺失、校验失败时在该 Worker 中调用 `recommend_wide_cross_js` 重建内存表。Worker 仅在用户展开时创建；折叠、关闭推荐、换打乱／模式／底色或销毁界面时终止正在工作的 Worker，并用请求代号拒绝迟到结果。原 `CrossAnalysisClient` 的 Worker 和原候选不受影响。BIN 作为版本化静态资源由浏览器缓存，避免每条候选重复下载。

Rust 返回的四朝向 `moves` 已按观察正面书写，且每条含 `u/u'`；Rust 内对完整魔方进行重放、校验 D 面 Cross 完成并限制 8 步。前端对返回结构、记号白名单、步数与朝向做严格校验，不借用只识别六面普通转动的 `applyFormulaFrom`／`isValidRecommendation` 过滤宽转。选中和播放以与 Rust 校验过的动作等价的 3D 动画重放来核对，而不是将未知记号静默忽略。

## 坐标、配色与预览

`crossf2l` 使用 `solveFacelets` 作为搜索快照；宽转物理动作由观察正面映射为现有魔方的动作，`u/u'` 绕竖轴不因 `F/L/B/R` 观察正面而改名。选中后沿用当前显示公式和播放流程，但不将宽转写进原普通面转解法列表或其最优步数。

`blecross` 使用与原推荐相同的 `analysisCoreBase` 快照。黄底直接求解；白底以 `toTrainFrame` 把目标映射到 Rust 的 D 面十字坐标。宽转从训练帧回到实体帧时必须与 `z2` 共轭一致：训练帧 `u/u'` 映射为实体帧对应的下两层宽转 `d/d'`，同时按现有 `y/y'` 视角链调整显示记号。映射的方向不能只凭字母替换推断，需用完整魔方状态或 3D 引擎测试对照 `z2 · u · z2`，并测试选中、逐步、播放、GIF 后十字判定与预览状态。白底不要求实体 BLE 魔方执行宽转作为一次设备事件：此功能只推荐和预览，不更改 BLE 训练账本。

## 错误处理与性能

普通推荐先按原链路完成；宽转搜索只在用户主动展开时启动。下载失败或 BIN 校验失败在独立 Worker 回退内存建表，并向用户显示「正在重建宽转表」；若最终仍失败，折叠区可重试，原推荐可继续使用。独立搜索设置 180 秒超时，超时则终止 Worker 并显示超时，不在主线程回退。切换轮次、关闭面板、折叠、重复点击应取消旧请求，不泄漏 Worker 或落入旧轮结果。所有搜索状态独立于主训练状态。

## 验收

1. 普通 Cross 推荐仍显示最短／+1／+2；折叠区默认不加载宽转 BIN，展开后两界面均显示含 `u/u'` 的四朝向候选或有边界的空结果。
2. 缓存 BIN 的候选与 Rust 参考结果一致；损坏／缺失 BIN 能在 Worker 内回退，最终失败只影响宽转区；折叠、关闭、换轮次能够取消旧搜索。
3. `crossf2l` 与 `blecross` 黄底／白底 `z2`／`y` 视角下的公式、指法、动画预览保持同一坐标，完整重放后目标 Cross 正确；未知记号被拒绝，不发生静默丢步。
4. 选宽转解法不改变训练结果、最优步数和 BLE 实体账本；构建产物包含同版本 WASM、宽转 Worker、宽转 BIN；既有 BLE 和固定公式测试继续通过。
