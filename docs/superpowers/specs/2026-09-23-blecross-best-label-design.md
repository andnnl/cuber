# BLE Cross 最优解标签精简设计

## 背景

Cross 训练的最优解区域当前显示 `最优解(白) 5步`。该标签在手机端占用空间较多，而用户只需要快速识别目标底色和最优步数。

## 展示方案

标签精简为“底色名+步数”，两者之间不加空格：

```text
白5步
```

底色名称继续使用当前视角状态：正常视角显示 `白`，开启 z2 后显示 `黄`。步数继续使用现有 `bestSteps` 计算结果。

最优解尚未就绪时只显示底色名称，不提前显示步数。公式内容、逐步预览、播放和 GIF 操作保持不变。

## 范围

仅修改 BLE Cross 的 Cross 最优解标签。XCross 的 FL、FR、BL、BR 槽位标签和其他模式界面不变。

## 验证

回归验证覆盖：

1. 模板不再包含 `最优解(` 格式。
2. 正常视角且最优解为 5 步时显示 `白5步`。
3. z2 视角且最优解为 5 步时显示 `黄5步`。
4. 最优解未就绪时只显示当前底色名称。
