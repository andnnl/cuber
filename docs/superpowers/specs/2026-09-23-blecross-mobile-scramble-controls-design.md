# BLE Cross 手机端打乱区域对齐设计

## 背景

BLE Cross 的操作行同时放置训练模式、打乱、重置、视角按钮和完整打乱公式。该行采用不换行的 Flex 布局，前面的控件均为固定宽度，公式区域则允许收缩并使用 `word-break: break-all`。

在约 360 px 宽的手机视口中，公式区域会被压缩到约 40 px，每个记号甚至每个字符都可能单独换行，最终形成一条很高的竖排文本。该问题会遮挡 3D 区域，也与 `mode=crossf2l` 的移动端交互不一致。

## 目标

- BLE Cross 的打乱输入和完整公式查看方式与 `mode=crossf2l` 保持一致。
- 手机端不再把完整打乱公式挤在操作按钮行中。
- 随机打乱、自定义公式打乱在手动练习、模拟魔方和真实蓝牙模式下使用同一轮次初始化语义。
- 保留 BLE Cross 已有的训练模式、重置、`z2`、`y`、`y'`、校准和帮助入口。

## 非目标

- 不调整训练状态、最优解、实时步骤或训练记录区域。
- 不改变打乱算法、十字判定和自动下轮逻辑。
- 不把 BLE Cross 改造成 CrossF2L 的收纳面板。
- 不修改 CrossF2L 页面本身。

## 界面设计

### 操作行

操作行保留以下控件：

1. 训练模式选择；
2. 「新打乱」；
3. 「重置」；
4. `z2`；
5. `y`；
6. `y'`；
7. 蓝牙连接时才显示的「校准」。

完整打乱公式从该行移除。操作行允许按控件整体换行，极窄屏或显示「校准」时不会挤压任何文本为单字符列。

### 自定义打乱输入行

在操作行下方新增与 CrossF2L 相同结构的独立输入行：

- 输入框占据剩余宽度，提示文字为「输入打乱公式，回车应用」；
- 按回车或点击 `✓` 应用公式；
- 点击 `🎲` 打开打乱信息弹窗；
- BLE Cross 已在连接信息行提供帮助按钮，因此不在输入行重复放置 `?`。

输入行中的输入框设置 `min-width: 0`，两个按钮保持固定宽度，保证 360 px 视口下仍为横向布局。

### 打乱信息弹窗

弹窗沿用 CrossF2L 的视觉结构：

- 标题为「🎲 打乱信息」；
- 正文以等宽字体展示完整公式；
- 提供「📋 复制公式」和「关闭」操作；
- 尚未生成打乱时禁用 `🎲` 按钮。

弹窗展示并复制 `scrambleText`，即当前用户实际可复现画面的完整公式。这样既保留随机或自定义的面转公式，也保留本轮已经纳入基准的视角记号。

## 交互与数据流

### 随机打乱

点击「新打乱」时，从现有 scrambler 生成公式，再进入统一的开轮流程。行为与当前实现保持一致。

### 自定义公式打乱

应用输入内容时：

1. 去除首尾空白，并把连续空白合并为一个空格；
2. 按 CrossF2L 的规则校验，仅接受 `U`、`R`、`F`、`D`、`L`、`B` 及 `'`、`2` 后缀；
3. 空输入不执行任何操作；
4. 非法输入不改变当前轮次，通过 `statusText` 提示公式无效；
5. 合法输入进入与随机打乱相同的统一开轮流程。

统一开轮流程按当前运行模式处理：

- 手动练习：从标准贴纸状态应用指定公式，恢复当前 `z2` 与基准持握，再进入观察阶段；
- 蓝牙或模拟魔方：以当前实体状态为基准推演指定公式，更新虚拟打乱目标并进入观察阶段；
- 若正在还原，应用新公式与点击「新打乱」一致，记录当前轮失败并结束旧轮；
- 自动下轮任务、计时、步数、历史、最优解和轮次同步均按现有新打乱流程重置。

### 复制公式

优先使用 Clipboard API；不可用或失败时，使用临时 `textarea` 和 `execCommand("copy")` 降级。复制成功后关闭弹窗，并通过 `statusText` 显示「✅ 已复制打乱公式」。复制失败时保留弹窗并提示用户手动选择复制。

## 实现边界

- `index.html`：调整操作行，新增输入行和打乱信息弹窗。
- `index.ts`：新增输入值、弹窗状态、公式校验、复制逻辑，并让随机与自定义公式复用同一个开轮入口。
- `theme.ts`：补充操作行换行、输入框和弹窗所需样式；不再依赖 `.scramble-text` 在操作行中布局。
- `scripts/verify-blecross-recompute.js`：增加移动端布局与自定义打乱交互回归验证。

## 测试设计

### 移动端布局

在 360 px 视口下验证：

- 操作行中不存在完整公式文本；
- 操作控件按整体换行，不产生单字符宽的文本列；
- 输入框、`✓` 和 `🎲` 均在卡片宽度内可见；
- 打乱信息弹窗中的公式具有可读宽度，可正常换行。

### 自定义公式

- 合法公式经空白归一化后成为当前打乱公式；
- 按回车与点击 `✓` 走同一入口；
- 非法公式保持当前轮次不变并显示错误；
- 手动与蓝牙模式均使用给定公式建立正确目标态；
- 正在还原时应用公式仍按现有规则记录失败。

### 弹窗与复制

- 无打乱时 `🎲` 禁用；
- 有打乱时弹窗展示 `scrambleText`；
- Clipboard API 成功和降级复制路径均复制完整公式；
- 成功后关闭弹窗并显示反馈。

### 回归验证

- 运行 BLE Cross 浏览器验证脚本；
- 运行 BLE 协议与状态测试；
- 执行生产构建，确认 TypeScript 和模板编译通过。

## 验收标准

- 截图所示手机宽度下不再出现竖排打乱公式。
- BLE Cross 的输入、应用、打乱信息和复制体验与 CrossF2L 一致。
- 随机打乱与自定义打乱除公式来源外没有轮次语义差异。
- 桌面端和现有 BLE 训练流程无回归。
