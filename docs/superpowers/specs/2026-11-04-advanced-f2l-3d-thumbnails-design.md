# 非标 F2L 案例 3D 缩略图设计

## 已确认的视觉方向

右侧案例网格采用视觉伴侣第二版的「A · 大图居中」结构，但将魔方略缩小：手机宽约 390px 时每行三张卡片。保留案例编号在上、缩略图居中、方向公式总数在下，选中项以现有青色边框和浅背景突出。桌面仍为三列；手机不再降为两列。卡片内图标目标占地约 75px，宽度按可用空间收缩，避免横向滚动。

页面增加一个「z2」复选框，默认关闭并记住用户选择。它控制整个非标 F2L 页面：主 3D 魔方与右侧所有案例缩略图同步切换到 z2 朝向。切换时停止当前动画、重建所选公式的起点并将步骤置零，后续播放在选定朝向下继续；返回页面时恢复勾选状态。其他页面的 z2 设置不受影响。

## 状态、颜色与绘制

沿用已有的 54 个案例离线 `setup` 生成每个案例的 54 格贴纸状态，取 U／F／R 三个 3×3 面；转换为九格小贴纸组成的等角立方体，而不是加载 54 个 WebGL 场景或第三方图片。卡片预览不受所选解法、槽位切换和动画进度影响，点击卡片仍由左侧主 3D 场景建立所选公式的独立起点。z2 采用「先整体转体，再执行逆公式／案例 setup」的统一规则；不是只换文字或颜色。

缩略图使用与本页面主魔方相同的有效配色，至少在打开页面时与当前存储的配色一致；不修改用户的配色配置。考虑到案例网格最多展示 18 项，预生成正常朝向和 z2 朝向的状态并复用，不在每次 Vue 渲染时重新求状态或调用 WebGL。缩略图保留正常边框、贴纸间隙，三面可辨认但不添加额外交互。

## 验证

- 自动检查 U／F／R 面各九格且所有 54 个案例都有可绘制状态，颜色映射没有未知面。
- 勾选 z2 后主场景与 54 个缩略图的朝向一起变化；播放中切换要停止并回到新起点，刷新页面恢复勾选，按公式播放后仍到达该朝向的还原态。
- 在桌面及 390px 手机宽度核对三列、不横向溢出、文字仍可辨认；筛选分组、选中卡片与公式播放保持原行为。
- 运行 `npm run test:adv-f2l` 与 `npm run build`。不修改工作区既有的其他功能和打包产物。
