# 非标 F2L 案例 3D 缩略图设计

## 已确认的视觉方向

右侧案例网格采用视觉伴侣第二版的「A · 大图居中」结构，但将魔方略缩小：手机宽约 390px 时每行三张卡片。保留案例编号在上、缩略图居中、方向公式总数在下，选中项以现有青色边框和浅背景突出。桌面仍为三列；手机不再降为两列。卡片内图标目标占地约 75px，宽度按可用空间收缩，避免横向滚动。

## 状态、颜色与绘制

沿用已有的 54 个案例离线 `setup` 生成每个案例的 54 格贴纸状态，取 U／F／R 三个 3×3 面；转换为九格小贴纸组成的等角立方体，而不是加载 54 个 WebGL 场景或第三方图片。卡片预览不受所选解法、槽位切换和动画进度影响，点击卡片仍由左侧主 3D 场景建立所选公式的独立起点。

缩略图使用与本页面主魔方相同的有效配色，至少在打开页面时与当前存储的配色一致；不修改用户的配色配置。考虑到案例网格最多展示 18 项，生成每个案例状态一次并复用，不在每次 Vue 渲染时重新求状态或调用 WebGL。缩略图保留正常边框、贴纸间隙，三面可辨认但不添加额外交互。
