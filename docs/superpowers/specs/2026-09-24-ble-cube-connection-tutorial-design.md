# 蓝牙魔方连接教程设计

## 目标

为 BLE Cross 训练增加一个独立的蓝牙连接教程页面，帮助用户先完成常规连接，再按顺序排查失败原因；仅在设备解密确实需要且自动获取失败时，引导用户填写 MAC 地址。

## 页面入口与导航

- 新增 `?mode=bleconnect` 页面。
- BLE Cross「使用说明」弹窗增加「蓝牙连接教程」按钮。
- 教程页顶部和底部均提供「返回训练」入口，回到 `?mode=blecross`。
- 教程首页首屏提供「进入训练并连接」主按钮，让已理解步骤的用户直接操作。

## 信息结构

页面采用用户确认的 A 方案「操作步骤优先」，顺序如下：

1. 三步完成连接：准备设备、发起连接、确认同步。
2. 连接失败排查：浏览器支持、权限、设备占用、距离、电量与重启。
3. 必要时获取 MAC：说明适用场景、设备机身优先、浏览器内部页仅作辅助。
4. 浏览器兼容性：明确推荐、受限和不支持的平台。

## 内容口径

- Web Bluetooth 正常连接不要求用户预先知道 MAC 地址。
- GAN Gen2 等设备可能需要 MAC 参与协议解密；项目会优先自动获取。
- 手动 MAC 是 `watchAdvertisements` 或自动识别失败后的兜底，不是通用连接前置条件。
- Chrome/Edge 内部蓝牙页面能否显示真实地址取决于操作系统、浏览器版本及隐私策略，不能保证。
- iOS/iPadOS 通常只向应用提供匿名标识，网页无法取得真实蓝牙 MAC。
- Firefox、Safari 不作为 Web Bluetooth 官方推荐路径；第三方浏览器或扩展只提示其兼容性不确定。
- 推荐路径为本项目 Android App、Android Chrome，以及电脑端 Chrome/Edge。

## 视觉与响应式

- 使用 Vuetify 现有风格，采用浅色教程页、步骤卡片和醒目的主操作按钮。
- 桌面端兼容性使用表格；窄屏改为纵向设备卡片，避免横向滚动。
- 页面正文最大宽度约 960 px；360 px 宽度下不出现横向溢出。
- MAC 示例使用等宽字体并允许自动换行。

## 验收标准

- `?mode=bleconnect` 能独立渲染教程。
- BLE Cross 使用说明能跳转到教程。
- 教程能返回 BLE Cross。
- 页面包含直接连接、失败排查、MAC 兜底、浏览器兼容性和隐私限制说明。
- 360 px 手机视口无横向溢出。
- BLE 既有测试、页面验证和生产构建全部通过。
