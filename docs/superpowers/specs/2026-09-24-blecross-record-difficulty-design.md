# BLE Cross 训练记录难度字段设计

## 目标

训练记录需要展示每一局开始时采用的难度，便于用户回看不同难度下的观察时间、还原时间和步数表现。

## 数据设计

在 `TrainRecord` 中增加可选的 `difficulty` 字段，值为 `random` 或 `2`～`7`。字段保持可选，以兼容 `localStorage` 中没有难度字段的旧记录。

每次开始打乱时，将当时生效的难度锁定为本轮难度。成功完成或中途失败写入记录时，使用这份锁定值，而不是记录写入瞬间的下拉框值。因此，用户在一轮进行中切换难度不会篡改当前轮的历史信息，新选择从下一次打乱开始生效。

自定义公式同样锁定当时下拉框的选择，用于表达用户发起该轮时的训练设置；该字段不声称自定义公式一定满足所选的精确最优步数。

## 列表展示

训练记录表新增“难度”列：

- `random` 显示为“随机”；
- 数字值显示为“2步”～“7步”；
- 旧记录或异常值显示为“—”。

难度列采用短文本和不换行样式，保持手机端表格可横向滚动，不压缩成逐字竖排。现有记录统计、条数筛选、清空记录和其他列保持不变。

## 兼容与校验

加载旧记录时不做破坏性迁移；展示层负责处理缺失值。新增记录只写入经过既有难度校验后的值。

自动化测试覆盖：

1. 当前轮记录保存开始打乱时锁定的难度；
2. 一轮中切换下拉框不会改变该轮记录；
3. 随机和数字难度的显示文本正确；
4. 旧记录缺少字段时显示“—”；
5. 表头包含“难度”，且手机端难度单元格不换行。
