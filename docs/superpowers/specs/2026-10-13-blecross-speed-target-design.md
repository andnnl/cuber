# BLE Cross 还原速度目标设计

在展开设置的“自动下轮 / 非最优重试 / 最优解”同一组中增加“速度目标”下拉框：关闭、≤1、≤2、≤3、≤5、≤8、≤10 秒。默认关闭，保存至 `bleSolveTimeTarget`；非法旧值回退关闭。手机窄屏允许设置组换行，收纳模式隐藏设置但继续显示结果。

正确完成 Cross 或 XCross 时，使用首次还原转动时刻 `solveStart` 到完成判定时刻的原始毫秒数判断；观察时间不参与。仅在有有效 `solveStart`、开启速度目标且用时严格大于目标时标记“速度未达标”。恰好等于目标算达标。结果继续显示成功，并补充“还原 X 秒，未达 ≤N 秒”；开启速度目标时结果向上显示到百分之一秒，避免刚超时的数值被舍入成看似达标。每次正确尝试仍记录为成功，保留还原用时。

“自动下轮”是所有自动跳转的总开关。开启时，成功结果展示 2.5 秒后，若“非最优重试”开启且步数不达标，或速度目标开启且用时超标，则调用现有 `resetRound()` 重练同一局；否则调用 `nextRoundDirect()`。关闭自动下轮时只显示结果，不跳转。成功展示期间修改设置要立即更新倒计时动作，不能重算已经完成的还原时间。禁用“最优解”不影响速度重试。

测试覆盖目标解析、边界与缺失计时、两种重试条件的或关系、设置记忆、倒计时分支、收纳/手机布局和训练记录。保持旧数据兼容，不新增记录字段。
