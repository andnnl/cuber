# v1.0.13 离线分卷发布实施记录

**目标：** 为 Gitee 提供 Windows `.bat` 与 Linux `.sh` 双击合包入口，无需 7-Zip；GitHub 发布完整安装包。

**实现：** `scripts/release-multipart.cjs` 按 90 MiB 切分现有桌面包，生成各平台合包脚本及标准 SHA-256 清单。Windows 使用 `copy /b`、`certutil`；Linux 使用 `cat`、`sha256sum`。已存在且内容不同的附件不得覆盖。

## 验证

- [x] `scripts/test-release-multipart.cjs` 先红后绿：90 MiB + 13 B 样本严格切两卷，Linux 正常还原、缺卷、损坏、重复和同名文件冲突均覆盖。
- [x] Windows 脚本生成后的分卷、校验命令、预期哈希与保护逻辑经静态测试；实际 Windows 双击待在用户 Windows 系统复验。
- [x] 最终脚本对真实 Linux AppImage 还原，比较原件 SHA-256；Windows 分卷比较原件拼接哈希。
- [x] 运行 Android、公式计时、桌面、BLE 回归测试以及 `git diff --check`。
