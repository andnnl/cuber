# 无缝 OP 重点线索与难度分级实现计划

> 面向 AI 代理的工作者：按用户偏好在当前工作区内联执行，不创建 worktree；未经用户要求不提交、推送。每步先写失败测试，再实现、验证。

**目标：** 按 OLL 轨迹找出最终六格来源均可见的相邻窗口，仅显示当前窗口的可见来源箭头，并让初学者先练满窗且移动较少的公式。

**架构：** `op-focus.ts` 只用 OLL 置换计算 F/R、R/B、B/L、L/F 的六格来源覆盖数；6/6 即满窗，不需要目标 PLL 身份。界面显示四窗口按钮，选中窗口可点来源或目标格看单条箭头；当前 B 面来源不画。全部轨迹复盘与已选公式池内的难度抽样保持可用。

**技术栈：** TypeScript、Vue 2、Node assert 测试、webpack、Playwright CLI。
